### Phase 1 — 헤더 React화
- `src/ui/GameHeader.tsx`로 제목·코인·CP·트로피·저장 상태·효과음/도움말/설정 버튼을 이전. 기존 클래스와 반응형 스타일 유지.
- 헤더는 Zustand의 재화·효과음·저장 상태를 selector로 구독. 레거시의 `renderHud()`에서 변경을 알려 `dirty()`를 거치지 않는 경기 입장 CP 차감도 반영.
- `bootV23()`이 헤더용 액션을 반환하고 `LegacyGame`이 전달. 헤더 DOM 수정·이벤트 바인딩은 레거시에서 제거하고, 기존 도움말·설정 모달은 액션으로 연결. 효과음·도움말 버튼은 v23 CSS(`#audioBtn,#helpBtn{display:none}`)대로 숨김 유지 — 두 기능은 설정 화면에서 사용.
- E2E 추가: 설정 화면 효과음 토글 ↔ 헤더 상태 동기화·설정에서 도움말 열기·포커스 복귀, 저장된 재화 표시·새 모험 초기화, 저장 실패 안내, 경기 시작 CP 차감.
- README·가이드·로드맵에 헤더 이전 상태와 연결 방식 반영.
